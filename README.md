## Контрольные вопросы


1. Проверяет элементы по очереди, пока не найдёт target (возвращает индекс) или не дойдёт до конца (возвращает -1)

2. Потому что ему всё равно, как лежат данные: он просто перебирает их подряд

3. Смотреть на середину диапазона и отбрасывать половину оставшихся элементов

4. Отбрасывать половину можно только зная, где именно находится target — это даёт именно сортировка

5. Линейный поиск растёт вместе с данными (миллион элементов — до миллиона проверок), а бинарному всегда нужно около 20 — разница тем заметнее, чем больше данных

6. Ручная реализация — для понимания алгоритма; в реальной программе берут готовый проверенный метод стандартной библиотеки

7. Линейный поиск двигается по одному элементу за раз, а бинарный каждый шаг отбрасывает половину — на миллионе элементов хватает примерно 20 шагов
